# Modul A — Algoritma Deskriptif

1. Mulai.
2. Masukkan kode barang.
3. Masukkan nama barang.
4. Masukkan stok awal.
5. Masukkan jumlah barang masuk.
6. Hitung stok tersedia dengan rumus:
   stok tersedia = stok awal + barang masuk.
7. Masukkan jumlah barang terjual.
8. Periksa apakah jumlah barang terjual melebihi stok tersedia.
9. Jika jumlah barang terjual melebihi stok tersedia, tampilkan pesan
   bahwa penjualan tidak valid dan minta pengguna memasukkan kembali
   jumlah barang terjual.
10. Jika jumlah barang terjual valid, hitung stok akhir dengan rumus:
    stok akhir = stok tersedia - barang terjual.
11. Masukkan stok minimum.
12. Masukkan harga beli.
13. Periksa stok akhir.
14. Jika stok akhir sama dengan 0, tentukan status stok sebagai Habis.
15. Jika stok akhir kurang dari stok minimum, tentukan status stok sebagai Menipis.
16. Jika stok akhir lebih besar atau sama dengan stok minimum,
    tentukan status stok sebagai Aman.
17. Jika status stok Menipis atau Habis, hitung jumlah barang yang harus
    dipesan sampai stok mencapai dua kali stok minimum.
18. Jika status stok Aman, jumlah barang yang harus dipesan adalah 0.
19. Tampilkan rincian persediaan barang.
20. Selesai.
