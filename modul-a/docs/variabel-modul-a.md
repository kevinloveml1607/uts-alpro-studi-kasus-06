# Modul A — Variabel dan Tipe Data

| No | Nama Variabel | Tipe Data | Nilai Awal | Kegunaan |
|---|---|---|---|---|
| 1 | kodeBarang | string | "" | Menyimpan kode barang |
| 2 | namaBarang | string | "" | Menyimpan nama barang |
| 3 | stokAwal | int | 0 | Menyimpan jumlah stok awal |
| 4 | barangMasuk | int | 0 | Menyimpan jumlah barang yang masuk |
| 5 | barangTerjual | int | 0 | Menyimpan jumlah barang yang terjual |
| 6 | stokMinimum | int | 0 | Menyimpan batas minimum stok |
| 7 | hargaBeli | double | 0 | Menyimpan harga beli barang per unit |
| 8 | stokTersedia | int | 0 | Menyimpan jumlah stok yang tersedia sebelum penjualan |
| 9 | stokAkhir | int | 0 | Menyimpan jumlah stok setelah penjualan |
| 10 | statusStok | string | "" | Menyimpan status Aman, Menipis, atau Habis |
| 11 | jumlahPesan | int | 0 | Menyimpan jumlah barang yang harus dipesan |
| 12 | ulang | char | 'y' | Menentukan apakah proses input barang diulangi |
